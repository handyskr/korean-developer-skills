# 인증·OAuth 용어

| 영어 | 쓰는 말 |
|---|---|
| Client ID | Client ID |
| Client Secret | Client Secret |
| Public Client | Public Client |
| Confidential Client | Confidential Client |
| client | 클라이언트 |
| Grant Type | Grant Type |
| Authorization Code | Authorization Code, 인가 코드 |
| PKCE | PKCE |
| JWKS | JWKS |
| JWT | JWT |
| OIDC | OIDC |
| access token | 액세스 토큰 |
| refresh token | 리프레시 토큰 |
| refresh token rotation | 리프레시 토큰 로테이션 |
| token family | 토큰 패밀리 |
| ID token | ID 토큰 |
| scope | 스코프 |
| claim | 클레임 |
| introspection endpoint | Introspection 엔드포인트 |
| revocation endpoint | Revocation 엔드포인트 |
| Principal | Principal |
| authentication | 인증 |
| authorization | 인가, 권한 |
| authorization server | 인가 서버 |
| issue | 발급 |
| issuer | 발급자 |
| consent | 동의 |
| credential | 자격 증명 |
| opaque token | 불투명 토큰 |
| signing key | 서명 키 |
| reuse detection | 재사용 감지 |

- authorization: 서버 이름은 "인가 서버", 요청마다 확인하는 단계는 "권한 확인"으로 쓴다.
- 코드 값은 백틱으로 쓴다. 예: `client_id`, `client_secret`, `grant_type`, `id_token`

## 고칠 때 찾아볼 말

| 찾아볼 말 | 바꿀 말 |
|---|---|
| 공개 client | Public Client |
| 비밀 client | Confidential Client |
| client 비밀 | Client Secret |
| client id | Client ID |
| access 토큰 | 액세스 토큰 |
| refresh (토큰 뜻) | 리프레시 토큰 |
| refresh 회전 | 리프레시 토큰 로테이션 |
| 인가 code | 인가 코드 |
| 증명 (credential 뜻) | 자격 증명 |
| 증명의 종류 | Grant Type |
