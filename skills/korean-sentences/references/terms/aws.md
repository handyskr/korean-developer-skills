# AWS 용어

| 영어 | 쓰는 말 |
|---|---|
| task definition | 태스크 정의 |
| health check | 헬스 체크, 상태 확인 |
| health check path | 헬스 체크 경로, 상태 확인 경로 |
| target group | 대상 그룹 |
| CIDR block | CIDR 대역 |
| environment variable | 환경 변수 |
| ALB | ALB |
| VPC | VPC |
| ECS | ECS |

- AWS 한국어 문서는 한 문서 안에서도 용어가 갈린다. 예: 제목은 "태스크 정의", 본문은 "작업 정의". 콘솔 화면 이름을 먼저 따른다.
