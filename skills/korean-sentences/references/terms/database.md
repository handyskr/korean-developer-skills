# 데이터베이스 용어

| 영어 | 쓰는 말 |
|---|---|
| table | 테이블 |
| row | 행, 로우 |
| record | 레코드 |
| column | 컬럼 |
| foreign key | 외래 키, FK |
| unique index | UNIQUE INDEX |
| lock | 락 |
| pessimistic lock | 비관적 락 |
| lock contention | 락 경합 |
| conditional update | 조건부 UPDATE |
| scan | 스캔, 조회 |
| isolation level | 격리 수준 |
| migration | 마이그레이션 |
| schema | 스키마 |

- table: DB 테이블만 "테이블"로 쓴다. 문서 안의 표는 "표"다.

## 고칠 때 찾아볼 말

| 찾아볼 말 | 바꿀 말 |
|---|---|
| 표 (DB 테이블 뜻) | 테이블 |
| 줄 (행 뜻) | 행 |
| 열 | 컬럼 |
| 잠금 | 락 |
| 잠금 다툼 | 락 경합 |
| 잠그며 읽기 | 락을 걸고 읽기 |
| 훑다 | 스캔하다 |
| 조건부 갱신 | 조건부 UPDATE |
| 유일 인덱스 | UNIQUE INDEX |
