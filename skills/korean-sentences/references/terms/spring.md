# Spring 용어

| 영어 | 쓰는 말 |
|---|---|
| bean | 빈 |
| profile | 프로필 |
| filter chain | 필터 체인 |
| Problem Details | Problem Details |
| placeholder | 플레이스홀더 |
| binding | 바인딩 |
| cache manager | 캐시 매니저 |
| application startup | 애플리케이션 시작 |
| health | health |
| readiness | readiness |

- 클래스와 어노테이션은 백틱으로 쓴다. 예: `SecurityFilterChain`, `ProblemDetail`, `@PreAuthorize`

## 고칠 때 찾아볼 말

| 찾아볼 말 | 바꿀 말 |
|---|---|
| 문제 응답 | Problem Details 응답 |
| 풀리지 않은 `${…}` | 해석되지 않은 플레이스홀더 |
| 묶이다 (바인딩 뜻) | 바인딩되다 |
| 캐시 관리자 | 캐시 매니저 |
| 기동 훅 | 시작 훅 |
