# 규칙이 생긴 사례

규칙(`rules.md`)이나 용어 목록(`terms/`)을 고치게 만든 문장을 모은다. 규칙 번호는 `rules.md`의 번호를 가리킨다. `korean-sentences-rules`가 규칙을 고칠 때 읽고, 새 사례를 맨 아래에 더한다. 규칙을 적용할 때는 읽지 않아도 된다.

- 회사나 프로젝트에만 있는 낱말, 사람 이름, 사용자의 말을 그대로 옮기지 않는다. 일반적인 예로 바꿔 적는다.

## 목차

(아직 없음)

## 사례 쓰는 꼴

```markdown
### 사례 N. <무엇이 어색했는지 한 줄> (YYYY-MM-DD)

대상: <글의 종류. 예: PR 제목, 설계 문서>

고치기 전:

> <원래 문장>

처음 고친 문장:

> <korean-sentences가 고친 문장>

최종:

> <규칙을 고친 뒤 다시 고친 문장>

처음 고친 문장이 어색했던 까닭: <한두 문장>

정한 것: <논의했으면 무엇으로 정했는지와 까닭>

원인: <규칙이 만들었다 / 규칙이 없었다 / 용어가 없었다 / 적용하다 놓쳤다 / 규칙끼리 부딪쳤다>. 고친 것: <규칙 번호나 파일>. 검사: <check.py에 넣었는지와 까닭>
```
